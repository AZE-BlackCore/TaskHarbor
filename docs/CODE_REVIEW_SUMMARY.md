## 🎯 核心特点

### 1. 三级审查标准

**🔴 阻塞性问题（必须修复）**
- 安全性问题（SQL 注入、XSS、Electron 安全）
- 数据完整性风险
- 关键路径错误处理缺失
- 破坏性变更

**🟡 建议性问题（应该修复）**
- 代码可维护性
- 类型安全
- React 最佳实践
- 性能优化

**💭 优化建议（可选）**
- 代码风格
- 文档完善
- 测试覆盖

### 2. 完整流程覆盖

```
提交前自查 → 创建 PR → CI 检查 → 人工审查 → 反馈修改 → 合并代码
```

每个环节都有明确的：
- ✅ 检查清单
- ✅ 操作指南
- ✅ 模板工具

### 3. 自动化优先

**能自动的绝不人工：**
- 类型检查（TypeScript）
- 代码格式（Prettier）
- 代码质量（ESLint）
- 功能测试（CI）

**人工专注高价值：**
- 架构设计
- 业务逻辑
- 安全性审查
- 代码可读性

### 4. 建设性文化

**核心理念：**
- 对事不对人
- 教导而非批评
- 平衡质量与效率
- 持续改进

```json
  }
}
```
