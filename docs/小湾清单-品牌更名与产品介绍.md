# TaskHarbor 正式更名为「小湾清单（Cove）」

> 一句话：**名字更好记了，技术标识一个字没动，你已配好的 MCP 完全不用改。**

---

## 为什么要改这个名字

用了半年的 `TaskHarbor`，传播时一直有三个绕不开的毛病：

| 问题 | 具体表现 |
|---|---|
| 太长、要拼写 | 10 个字母、3 个音节、双词拼合。口头推荐得补一句"Tasks 那个 Task，Harbor 那个 Harbor" |
| 拼写会分叉 | Harbor（美式）/ Harbour（英式）两条路，中文读者往往只记住后半截"那个什么 Harbor" |
| 差异化没进名字 | 真正的卖点——AI Agent 能直连读写、数据本地私密——名字里一个字都没体现 |

于是我们把它缩短成一个词：**Cove，中文名「小湾清单」**。

## 新名字：小湾清单（Cove）

**Cove** 是「小湾」——一处安静、私密的水湾。

不是大港口，不吞吐万吨巨轮，只停靠属于你自己的那几条小船：今天要做的事、下周要交的活、某个突然冒出来的想法。它们驶进来，安静地泊在水面上，等你从容启航。

这个名字同时讲清了三件事：

- **小**：体量轻，单机安装即用，不占心智
- **私密**：水面只属于你——数据完全落盘本地 SQLite，不上传云端
- **停靠与启航**：既收得住（任务不丢、不散），也放得出（有节奏地推进）

**Slogan：把任务停靠进你的小湾。**

## 新 Logo：小船停湾

![小湾清单 Logo](./assets/app-logo.svg)

中心意象是「小湾水面 + 停泊的小船 + 一面金色对勾帆」：

- 水面弧线 = 小湾
- 停泊的小船 = 任务停靠
- 帆做成对勾 = 清单完成的仪式感

配色沿用原来的蓝紫渐变（`#3B82F6 → #8B5CF6`）与金色点缀（`#FBBF24 → #F59E0B`），老用户看一眼就能认出来。

## 最重要的部分：你不用改任何配置（双轨制）

改名最怕的是"改出事故"。所以我们采用**双轨制**——对外换名字，对内一个字不动：

| 层面 | 处理 |
|---|---|
| **对外传播名** | 小湾清单 / Cove（README、窗口标题、托盘、安装包名、关于对话框、导出报告落款） |
| **内部技术标识** | 全部保留 `TaskHarbor`：npm 包名 `taskharbor`、appId `com.taskharbor.desktop`、环境变量 `TASKHARBOR_*`、MCP server id `taskharbor` 及全部 `taskharbor_*` 工具名、HTTP API 端口 `18765` |

**对你的实际影响：零。**

- 已配好的 `mcp.json` **不需要动一个字符**，Agent 照常读写。
- 升级安装**不会覆盖你的数据**（数据库在 `%APPDATA%\taskharbor\todolist.db`）。
- 唯一会变的是：窗口标题、桌面快捷方式名、开始菜单项变成「小湾清单」。

顺带一提：安装目录名仍是 `%LOCALAPPDATA%\Programs\taskharbor`。这是有意为之——electron-builder 只在产品名为纯 ASCII 时才用它做目录名，中文会回退 npm 包名；保持 `taskharbor` 既符合双轨制，也避开了中文路径在杀软、备份工具上的兼容坑。

## 顺手修掉的一个坑（1.6.2）

更名过程中暴露了一个真实回归：图标从 `build/` 迁移到 `renderer/public/` 后，打包态的托盘图标查找路径没同步更新，导致 `new Tray('')` 抛错并中断主初始化——窗口能开，但托盘图标和菜单是坏的。

1.6.2 已修复，并顺手加了**主进程文件日志**（`%APPDATA%\taskharbor\logs\main.log`）。以后遇到启动异常，把这个文件发出来就能精确定位，不用再靠猜。

> 另外一个高频问题：**装完双击没反应**。八成是杀软在拦——未签名的新 exe 首次被实时扫描时，安装器会直接崩 `0xC0000005`。关掉实时防护重装，或把安装包复制到别的目录再装，基本一次就好。

## 这个应用能干什么

- **Day Todo**：以今天为中心的 7 天滚动条，日程与任务共用一条时间轴
- **最近待办 / 待办箱**：按今天 / 本周 / 本月过滤，状态与优先级筛
- **日程管理**：月历 + 日视图，重复事件、提醒、任务关联
- **标签系统**：自定义颜色，真实统计
- **数据复盘**：六维统计、智能分析、Markdown 报告导出
- **智能提醒**：逾期 / 今日 / 明日 / 即将到期的分级提醒 + 桌面通知
- **Agent 接入（核心差异点）**：内建本地 HTTP API（`127.0.0.1:18765`）+ 零依赖 MCP Server，8 个工具让 WorkBuddy / Claude / 任意 AI Agent 直接创建、查询、修改、删除你的任务与日程

## 怎么获取

- **用户数据目录**：`%APPDATA%\taskharbor\`（数据库与日志都在本地）
